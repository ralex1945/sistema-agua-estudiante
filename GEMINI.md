# Reglas del Proyecto

## Control de Versiones (Git)
- **PROHIBIDO hacer `git commit` o `git push` automáticamente.**
- El asistente NUNCA debe ejecutar `git commit` ni `git push` por cuenta propia.
- El usuario es el único responsable de hacer commit y push cuando lo considere oportuno, salvo que pida expresamente ejecutar dichos comandos.
